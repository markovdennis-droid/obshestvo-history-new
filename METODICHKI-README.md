# Страница методичек — как обслуживать

## Файлы

- `metodichki.html` — страница каталога (открывается в новой вкладке);
- `metodichki.css` — стили только этой страницы;
- `assets/pdf/` — PDF бесплатных методичек;
- `index.html`, `styles.css` — обновлены: добавлен блок «Методички» в разделе
  «Подготовка», пункт в мобильной навигации и ссылка в подвале.

## Как добавить новую методичку

Весь каталог живёт в одном месте — в массиве `CATALOG` внизу `metodichki.html`.
Каждая тема (вкладка) выглядит так:

```js
{
  id: "drevnyaya-rus",        // латиницей, уникально
  tab: "Древняя Русь",        // подпись на вкладке
  title: "Древняя Русь",
  period: "IX–XV века",
  note: "текст под заголовком темы",
  items: [ ... ]              // 10–15 выпусков
}
```

Выпуск:

```js
{
  n: 3,                                   // номер на обложке
  title: "Политическая раздробленность",
  sub: "1132–1237 · Новгород · Владимир-на-Клязьме",
  meta: "20 страниц · 60–75 минут · 13 заданий",
  status: "sale",                         // free | sale | soon
  file: "assets/pdf/....pdf",             // только для free
  pay: "https://yookassa.ru/..."          // только для sale
}
```

- `free` — кнопка «Скачать PDF», файл берётся из `file`;
- `sale` — кнопка «Купить за 350 ₽»; если `pay` пустой, открывается окно с
  предложением написать в Telegram;
- `soon` — карточка приглушена, кнопка неактивна.

Цена меняется в одной строке: `var PRICE = 350;`

## Подключение ЮKassa

1. В личном кабинете ЮKassa создайте товар/платёжную ссылку на 350 ₽ для
   каждой методички.
2. Скопируйте ссылку в поле `pay` соответствующего выпуска.
3. Кнопка сразу начнёт вести на оплату — код менять не нужно.

Автоматическую выдачу файла после оплаты ЮKassa сама не делает: настройте
письмо со ссылкой в личном кабинете либо отправляйте PDF вручную/через бота.

## Важно про платные PDF

Не кладите платные методички в `assets/` — репозиторий GitHub Pages открыт, и
файл скачается по прямой ссылке без оплаты. В `assets/pdf/` держите только
бесплатные выпуски. Платные храните там, где ссылка выдаётся после оплаты
(облако с ограниченным доступом, письмо, Telegram-бот).
