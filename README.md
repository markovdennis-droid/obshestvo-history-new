# Сайт репетитора Евгении Александровны

Готовая статическая версия для GitHub Pages. Сложные зависимости и сборка не нужны.

## Как загрузить на GitHub Pages

1. Откройте репозиторий `obshestvo-history` на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css` и папку `assets`.
3. Сохраните изменения кнопкой **Commit changes**.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Укажите ветку `main`, папку `/ (root)` и нажмите **Save**.

Публиковать или заменять файлы действующего сайта следует только после отдельного подтверждения владельца.

## Состав

- `index.html` — вся структура и тексты страницы;
- `styles.css` — дизайн и мобильная адаптация;
- `assets/approved-cover.png` — утверждённая обложка без изменений.
